Lossless Compression

Aim: Implement a lossless coding technique and compare original and compressed file sizes.

This browser practical demonstrates Run-Length Encoding (RLE), a lossless coding technique. The compressed size shown is the RLE stream size estimate, not a replacement for PNG/JPEG file size.
